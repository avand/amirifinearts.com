# amirifinearts.com

The website of [Fahimeh Amiri](https://amirifinearts.com) — paintings, Persian
miniatures, children's book illustrations, and posters.

Static site, built with Jekyll, hosted on GitHub Pages. Migrated from
Squarespace in August 2026.

```sh
bundle install
bin/dev            # http://localhost:8200 and https://afa.avand.dev
```

Deploying is merging to `main`.

See [CLAUDE.md](CLAUDE.md) for how to add a painting, where the content came
from, and the handful of things that still need Fahimeh's input.
