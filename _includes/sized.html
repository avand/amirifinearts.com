{%- comment -%} The URL of an image's smaller copy, made by bin/resize. {% include sized.html image="/images/works/koala.jpg" width=480 %} => /images/sized/480/works/koala.jpg Every copy is a JPEG, whatever the original was. The widths that exist are whatever WIDTHS in bin/resize says: 240, 480 and 960. There is also width="full" for a work: the original's size, made to load progressively. A work that was already a progressive JPEG has no full copy, and gets its original from here -- which is exactly what it should get. If the copy is not there -- a photo added without bin/dev running, so nothing made its copies -- this gives back the original instead. The page is slower for it, but every image still shows. The lookup is against site.static_files, the files Jekyll is about to publish, so it can only name one that exists. {%- endcomment -%} {%- unless sized_files -%} {%- assign sized_files = site.static_files | map: "path" -%} {%- endunless -%} {%- assign sized_stem = include.image | remove_first: "/images/" | split: "." | pop | join: "." -%} {%- assign sized_path = "/images/sized/" | append: include.width | append: "/" | append: sized_stem | append: ".jpg" -%} {%- if sized_files contains sized_path -%} {{- sized_path | relative_url -}} {%- else -%} {{- include.image | relative_url -}} {%- endif -%}
