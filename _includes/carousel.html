{% comment %} A slideshow with a thumbnail strip, as the Squarespace gallery blocks had: one large image, arrows either side, and every image as a thumbnail below. Takes `images` (a list of {image, caption}) and `id` (unique on the page -- the Classes page has a carousel and a grid, and Profile has its own). It renders every slide as real markup rather than building them in script, so the images are in the HTML for search engines and for anyone with JavaScript off. Without script it degrades to the first slide plus the strip, which is a static page rather than a broken one. carousel.js does the rest. Images are bin/resize's, named as in the data files ("gallery/gallery-01"). Their width and height reserve the space before they load. A slide is at most about 540px wide (Profile's column) and the full width of a phone below that; a thumbnail is at most 100px tall, which the 240 copy covers at 2x. {% endcomment %}
