{% comment %} A slideshow with a thumbnail strip, as the Squarespace gallery blocks had: one large image, arrows either side, and every image as a thumbnail below. Takes `images` (a list of {image, caption}) and `id` (unique on the page -- the Classes page has a carousel and a grid, and Profile has its own). It renders every slide as real markup rather than building them in script, so the images are in the HTML for search engines and for anyone with JavaScript off. Without script it degrades to the first slide plus the strip, which is a static page rather than a broken one. carousel.js does the rest. {% endcomment %}
